# Licco ESD FaceAuth Attendance & HR Management System

An enterprise-grade, full-stack web application built on the MERN stack that automates employee attendance tracking using facial recognition. The platform provides Human Resources departments with comprehensive tools to manage incidents, analyze employee behavior, and generate pre-payroll reports.

## Key Features

### 📡 Automated Facial Recognition Attendance
* **Biometric Check-in/out:** Real-time employee identification using facial recognition models.
* **Spoof Detection:** Prevents attendance fraud using static images or videos.

### 🏢 HR Administration Portal
* **Incident Management:** Easily review, modify, approve, or reject employee attendance incidents (e.g., lateness, unjustified absences, justifications).
* **Employee Behavior Analytics:** Data-driven dashboards displaying punctuality trends, absenteeism rates, and behavioral patterns.
* **Pre-Payroll Generation:** Automatically calculate billable hours and generate structured pre-payroll reports for seamless accounting integration.

---

## Technical Stack

* **Frontend:** React, Redux (State Management), i18next (Internationalization)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Core Libraries:** Face-api.js (or specified facial recognition ML model wrapper), Axios
